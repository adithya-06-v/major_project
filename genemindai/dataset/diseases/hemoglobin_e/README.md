# Hemoglobin E Disease

This folder is reserved for Hemoglobin E disease test data.

## Purpose
This dataset supports multi-disease testing where the model must distinguish HBB-related hemoglobin variants.

## Suggested source types
- ClinVar variant annotations
- HBB variant reference databases
- Published HBB mutation collections
- Synthetic validation samples

## Files
- `sample_test_dataset.csv` — example dataset used for testing
- `raw/` — source references or notes
- `processed/` — cleaned or transformed data
