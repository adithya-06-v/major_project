# Beta Thalassemia

This folder is reserved for Beta Thalassemia test data.

## Purpose
This disease-specific dataset complements the multi-disease testing setup and keeps Beta Thalassemia as one of the model classes.

## Suggested source types
- ClinVar records for HBB pathogenic variants
- Beta-thalassemia mutation catalogs
- HBB-specific curated references
- Synthetic local validation samples

## Files
- `sample_test_dataset.csv` — example dataset for local validation
- `raw/` — source notes or downloaded references
- `processed/` — cleaned / transformed data
