# Sickle Cell Disease

This folder is reserved for Sickle Cell Disease (SCD) test data.

## Purpose
This dataset is prepared for multi-disease testing workflows and should be used only for local validation, experimentation, and model smoke tests.

## Suggested source types
- ClinVar variant records
- HGMD or curated disease mutation databases
- Public HBB mutation catalogs
- Synthetic test samples generated from HBB variant patterns

## Files
- `sample_test_dataset.csv` — example dataset used for testing the model pipeline
- `raw/` — original references or notes
- `processed/` — cleaned and feature-engineered data if needed
