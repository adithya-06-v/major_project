# Disease-specific test datasets

This folder contains separate dataset folders for diseases that are being prepared for multi-disease testing.

Each disease folder is organized as:

- `README.md` — disease summary and source notes
- `sample_test_dataset.csv` — small synthetic dataset for local validation/testing
- `raw/` — source references or notes
- `processed/` — cleaned/derived datasets

These files are intended for test and development purposes. They should be replaced or expanded with validated real-world datasets before production use.

## Included disease folders

- `beta_thalassemia/`
- `sickle_cell_disease/`
- `hemoglobin_e/`
- `hemoglobin_c_disease/`
