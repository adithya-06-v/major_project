# Hemoglobin C Disease

This folder is reserved for Hemoglobin C disease test data.

## Purpose
This disease-specific dataset supports multi-disease validation by holding separate examples for HBB-related hemoglobin disorders.

## Suggested source types
- ClinVar submissions
- HBB disease mutation databases
- Synthetic sequence examples for local testing
- Publicly available hemoglobinopathy datasets

## Files
- `sample_test_dataset.csv` — example dataset for local model testing
- `raw/` — downloaded or reference materials
- `processed/` — cleaned and feature-engineered data
